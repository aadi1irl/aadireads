# 🌌 MangaVerse

### Discover your next favourite story.

MangaVerse is a manga and manhwa discovery website built for readers who love exploring new stories. Discover titles, browse manga collections, and explore a clean, modern interface.

---

## ✨ Features

- 🔎 **Manga Search** – Search for manga and manhwa titles.
- 📚 **Discover** – Explore manga from the AniList catalogue.
- 🖼️ **Cover Gallery** – Browse titles with cover artwork.
- 🌙 **Dark UI** – A modern, manga-inspired design.
- 📱 **Responsive Design** – A user-friendly experience across screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- [AniList GraphQL API](https://anilist.gitbook.io/anilist-apiv2-docs/)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MangaVerse.git
```

### 2. Open the project folder

```bash
cd MangaVerse
```

### 3. Run the website

Open `index.html` using the VS Code Live Server extension.

No backend server or database is required.

## 🔌 API

MangaVerse uses the AniList GraphQL API to retrieve manga catalogue information.

API endpoint:

`https://graphql.anilist.co`

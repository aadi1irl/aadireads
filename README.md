# 🌌 MangaVerse

### Your universe of manga and manhwa.

MangaVerse is a manga and manhwa discovery website designed for readers who want to explore titles, discover new stories, and enjoy a clean reading experience.

---

## ✨ Features

- 🔎 **Search:** Find manga and manhwa titles.
- 📚 **Discovery:** Explore different series.
- 🖼️ **Cover Gallery:** Browse titles with their cover artwork.
- 🌙 **Dark UI:** A modern, manga-inspired interface.
- 📱 **Responsive Design:** Designed to work across different screen sizes.
- 🔗 **Kagane Integration:** Uses the Kagane community API for catalogue discovery.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Kagane API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MangaVerse.git
```

### 2. Open the project

```bash
cd MangaVerse
```

### 3. Run the website

Open `index.html` using VS Code Live Server.

No backend server or database setup is required.

## ⚠️ Notes

- MangaVerse uses a community API, which may change or become unavailable.
- Direct API requests from the browser depend on CORS support.
- Chapter reading may redirect to the original platform.
- MangaVerse does not host or claim ownership of third-party manga content.
